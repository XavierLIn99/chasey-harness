# 追追 · DeepSeek Harness 会话图谱

在长对话里找到之前的回答，选中一句话或一个公式，沿着它继续提问。新回答会出现在同一条 Harness 对话里，也会在画布上从原来的那一轮长出一条支线。

[English](README.md)

## 开始使用

1. 在[最新版本](https://github.com/XavierLIn99/chasey-harness/releases/latest)下载插件压缩包并解压。
2. 在 DeepSeek Harness 中打开「插件 → 添加插件」，选择解压后含有 `package.json` 的文件夹。
3. 打开对话，点击「追追」并选一张卡片。划选原文，点击「追问这段」即可提问。

追追按设备或浏览器的语言偏好显示简体中文、繁体中文或英文。若列表中没有支持的语言，界面使用英文。问题、回答和公式保留原文。

## 阅读画布

粗线表示对话顺序，细线连接追问和它的来源。点击「连回卡片」可以手动添加虚线。拖动卡片可调整布局，双指捏合可缩放，输入轮次可跳回旧回答。

打开画布不消耗模型用量。发送追问时，Harness 使用当前会话配置的模型。卡片位置与手动连线保存在本机。图片和文件显示为占位符。

适配 DeepSeek Harness Desktop / Web 0.2.2-rc.5。[开发与鸣谢](README.md#development)
