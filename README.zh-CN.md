# 追追 · Chasey for DeepSeek Harness

把当前会话放在一张可追问的画布上。点击任意一轮，阅读问题和回答，在原文中选中一句继续提问。新问题会进入同一条 Harness 会话，回答完成后出现在图谱上。

## 本地试用

适配官方 DeepSeek Harness Desktop / Web **0.2.2-rc.5**。在 Harness 的 **插件 → 添加插件** 中选择本目录（含 `package.json`）。插件已包含构建产物，试用无需 npm 安装。打开已有会话，点击会话标题旁的 **追追**；也可从右侧面板新增标签页，选择 **追追 · 会话图谱**。

- 打开画布会定位到最新一轮。拖动空白处平移，拖动卡片可调整位置；松手后会在本机保存该会话的布局。触控板双指滑动平移，双指捏合缩放；触摸屏支持双指缩放。长对话可在工具栏输入轮次并按回车，直接打开对应卡片；点击「定位」可找回当前卡片。
- 点击卡片可打开原文，卡片会居中到阅读面板上方。刷选文字，点击选区旁的 **追问这段**，即可带着原文填写问题。
- 粗线记录普通消息的先后顺序，细线表示有原文出处的追问。对于 Harness 旧刷子，追追会在已加载回答中查找能唯一对应的引文，来源不清楚时保留引文，同一轮内的引用会标为「引用本轮原文」。
- 在卡片原文的输入框写问题，点击 **发送到本会话**。选中的文字会以引用进入请求；没有选段时附上本轮的一小段文字。已有的主聊天草稿保持独立。费用与权限沿用当前 Harness 会话。
- 点击 **连回卡片**，再点目标卡片，可建立金色虚线。重新打开来源卡片即可移除。右侧面板支持 Harness 自带的全屏和分离操作。
- 较早记录通过会话接口分页加载。首版展示用户提问和已完成的文字回答，图片与文件只显示占位。每次打开只读取选中的会话。
- 图谱直接从宿主会话重建。手动回连和卡片位置保存在当前客户端的本地存储中。发送追问时，Harness 会按用户已配置的模型服务处理问题与上下文。追追没有单独的服务器或模型密钥。

点击卡片后，阅读面板将提问和回答分开排版，底部可以继续追问。用轮次两侧的箭头切换原文，或点击「展开阅读」使用整个追追面板。切换轮次后再回来，可以接着编辑同一面板里尚未发送的草稿。

数学排版沿用 Harness 内置的 KaTeX 和数学字体。问题、回答、卡片及选段均支持带定界符的 LaTeX，较宽的独立公式可以横向滚动。刷选已排版的公式时，追问会附上对应的 LaTeX 原文。

## 开发

使用 Node.js 22+。运行 `npm ci`、`npm test`、`npm run build`。浏览器入口通过官方 client module loader 使用宿主的 React 和 Markdown 组件。Host 入口不读取文件，也不注册网络服务。
